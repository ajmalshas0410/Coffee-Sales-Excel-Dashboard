# Coffee Sales Excel Dashboard

## Project Overview

This is my first Excel analytics project. I worked with a coffee sales dataset containing Orders, Customers and Products, and built an interactive dashboard to explore sales performance.

## What I Worked On

- Data preparation and combining information from the customers and porducts tables
- VLOOKUP and INDEX-MATCH
- IF functions and calculated fields
- Excel Tables
- PivotTables and PivotCharts
- Slicers and Timeline

## Dashboard

The dashboard includes:

- Total Sales
- Total Orders
- Total Quantity Sold
- Sales Trend by Coffee Type
- Sales by Country
- Top 5 Customers
- Interactive slicers and timeline

## Tools

- Microsoft Excel

## Project Outcome

The project helped me apply the Excel concepts I have been learning to a practical dataset and understand the workflow from data preparation to analysis and visualization.
